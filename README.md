# 간호 컨셉맵 빌더

간호대학생을 위한 임상 실습 컨셉맵(사정 → 간호진단 → 계획 → 중재 → 평가) 작성 도구입니다.
과목/주차별로 정리해서 시험 전에 검색·복습할 수 있도록 돕는 것이 목적입니다.

## 주요 기능

- **목록**: 과목별 탭 필터, 주차 필터/정렬, 키워드 검색(케이스 제목/간호진단명), 즐겨찾기 필터
- **편집**: 사정(S/O 데이터), 간호진단(여러 개 추가/삭제, 우선순위 자동 관리), 목표(단기/장기), 중재(독립적/의존적 구분), 평가를 진단별 세트로 묶어서 입력
- **상세 보기**: 사정 → 진단 → 계획 → 중재 → 평가 흐름을 화살표로 연결한 카드 레이아웃, 수정/삭제/즐겨찾기, 인쇄 및 PDF 내보내기
- **다크모드**, 반응형 레이아웃, `localStorage` 기반 데이터 저장(백엔드 없음)

## 기술 스택

React 19 (Hooks), Vite, Tailwind CSS v4

## 개발

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

`main` 브랜치에 푸시하면 GitHub Actions가 자동으로 빌드 후 GitHub Pages에 배포합니다.
